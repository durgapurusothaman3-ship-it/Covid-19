COVID-19 Data Analysis & Dashboard System

A complete Exploratory Data Analysis (EDA) and Interactive Dashboard project using real-world COVID-19 data from Kaggle.
This project analyzes global COVID-19 trends including confirmed cases, deaths, recoveries, and active cases using Python and visualization libraries.

Project Overview

The COVID-19 pandemic generated massive amounts of real-time health data across countries.
Manually analyzing this data is difficult and time-consuming.

This project helps to:

Analyze real-world COVID-19 data
Identify trends and patterns
Compare countries
Visualize pandemic growth
Build an interactive dashboard

Dataset Information

Dataset: Corona Virus Report Kaggle dataset
